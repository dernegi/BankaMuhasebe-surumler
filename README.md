# BankaMuhasebe — kurulum dosyaları

Bu depoda yalnızca BankaMuhasebe programının kurulum dosyaları durur. Dosyalar **Releases** (Sürümler) bölümündedir.

| Dosya | Kimin için |
|---|---|
| `BankaMuhasebe-Kurulum-X.Y.Z.exe` | Windows: hem yeni kurulum hem güncelleme. Çift tıklamak yeter, verileriniz korunur. |
| `BankaMuhasebe-X.Y.Z-Mac.dmg` | Mac: hem yeni kurulum hem güncelleme (Apple işlemcili ve Intel). |

Program kurulduktan sonra yeni sürümleri kendisi haber verir: üst çubuktaki **Güncelle** düğmesi.

Program internete muhasebe verisi göndermez; kurulum dosyalarında hiçbir kurumun verisi yoktur.
